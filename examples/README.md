# LLM-LAMMPS / examples

Flat dump-all folder for reference artifacts: LAMMPS input fragments,
gnuplot recipes, submit-script archetypes, closed-thread exemplars,
OVITO snippets, etc.

**Non-prescriptive.** Contents here are reference, not policy. Pilot
consults them only when the user points at a specific file. See
ARCHITECTURE.md §6 for the role definition.

**Flat structure** — no subfolders. Use descriptive filenames; the
catalog (`canon/examples-catalog.md`) groups by type.

**Adding to examples:** the user instructs ("add this input as an
example"); pilot copies the file in and updates the catalog. Catalog
refresh is on-demand only ("recatalog examples").
